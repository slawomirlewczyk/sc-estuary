[B]SC Estuary 1.5.4[/B]
- joined widgets: the last tile goes to the next page again, not back to the
  previous one (FanFilm lists for widgets carry only a "previous page" tile)

[B]SC Estuary 1.5.3[/B]
- removed "Mark as watched / unwatched (FanFilm)" from the widget context
  menu and its notification; mark movies in FanFilm instead

[B]SC Estuary 1.5.2[/B]
- "Hide watched movies" also uses Kodi's own watched marks of add-on movies
  (what the FanFilm window shows), which add-on lists for widgets leave out
- widget tiles show the watched checkmark for add-on movies

[B]SC Estuary 1.5.1[/B]
- "Hide watched movies" now also works with FanFilm's local watched status
  (no Trakt): widgets read FanFilm's local marks, remember movies played to
  85 % and movies marked from the widget menu, and Kodi library plays

[B]SC Estuary 1.5.0[/B]
- "Sort widgets by rating (highest first)" (Skin settings > Home > Movies):
  Filmweb rating, else IMDb, else the add-on's own
- Joined widgets: "next page" tiles no longer appear between movies; only the
  last page's one is kept, at the end

[B]SC Estuary 1.4.0[/B]

  widget tiles show the Filmweb rating, else IMDb, else the add-on's own

[B]SC Estuary 1.3.0[/B]

  the source add-on marks as watched; widgets reload by themselves after
  playback stops

[B]SC Estuary 1.2.0[/B]
- "Hide duplicate movies" (Skin settings > Home > Movies): a movie shown in a
  higher widget is left out of the widgets below it
- duplicates inside one widget are matched by IMDb/TMDb id, not by URL

[B]SC Estuary 1.1.1[/B]

  (Manage widgets menu, Skin settings > Home > Movies)
